France

All businesses must receive e-invoices from September 2026; issuing phases in 2026–2027.

Dates summarised from public sources; always confirm with your country's tax authority.

How it works

1. Send JSON

Seller, buyer, lines and VAT rates. No totals: we calculate them, so arithmetic errors can't happen.

2. Get a Factur-X PDF

A normal PDF/A-3 invoice with the EN 16931 XML embedded. Readable by people and accounting software.

3. Validate anything

Upload XML (UBL or CII) or a Factur-X/ZUGFeRD PDF. Errors come with rule IDs and plain-English hints.

Private by design

Invoice contents are processed in memory and never stored. We only count your calls.

Try it

curl -X POST {{ base_url }}/v1/invoices \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  --data @invoice.json \
  -o invoice.pdf

curl -X POST {{ base_url }}/v1/validate \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/pdf" \
  --data-binary @invoice.pdf
